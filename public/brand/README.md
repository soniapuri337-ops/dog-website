# Brand assets

- `logo.svg`     the header and footer mark. Replace with your own square logo
                 (svg, png or jpg). Update the path in `src/data/site.js` if you
                 change the filename.
- `favicon.svg`  the browser tab icon. Same idea.

The mark renders inside a 44px rounded square, so a square or centred logo
works best. If the file is missing, the lockup falls back to a paw mark.
